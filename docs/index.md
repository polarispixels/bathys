# Bathys

Bathys is a private book catalog. It holds the shelf (books Ryan owns) and the wishlist (books he wants), sorted into categories he defines himself. Each book has one rating: how deep he has read it, on Mortimer Adler's levels of reading. It is also a teaching codebase, so the docs explain why the code is shaped the way it is.
